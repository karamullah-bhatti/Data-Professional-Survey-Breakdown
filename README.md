# Data Professional Survey Breakdown | Power BI

## Project Overview
This project presents an interactive Power BI dashboard analyzing survey responses from data professionals. The dashboard explores different aspects of the data industry, including job roles, salaries, programming language preferences, career satisfaction, and geographical distribution.

The objective is to transform raw survey data into meaningful insights that help understand the current landscape of data-related careers.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Project Objectives
- Analyze the distribution of survey respondents across different countries.
- Compare average salaries across various data-related job roles.
- Identify the most popular programming languages among data professionals.
- Explore job satisfaction and work-life balance.
- Understand the challenges faced by individuals entering the data industry.

## Dashboard Highlights
- Total survey respondents
- Average salary by job title
- Country-wise respondent distribution
- Favorite programming languages
- Happiness with salary
- Happiness with work-life balance
- Difficulty breaking into the data industry

## Skills Demonstrated
- Data cleaning and transformation using Power Query.
- Data modeling and preparation.
- Building interactive dashboards.
- Creating meaningful visualizations.
- Analyzing survey data and communicating business insights.
